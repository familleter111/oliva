# Photos de démonstration

Ces images servent uniquement aux données de démonstration (`npm run demo:seed`) et à la décoration de l'interface (`public/brand/`).
Elles proviennent d'Unsplash (licence Unsplash : usage libre, y compris commercial, sans attribution obligatoire).

Remplacez-les par les photos de votre restaurant depuis la médiathèque de l'administration.
